# Contributing

Thanks for your interest in improving this project.

This repository is designed to be a clean, beginner-friendly Android guide and a lightweight WebView-based learning app. Contributions that improve readability, usability, documentation, and maintainability are welcome.

## How to contribute

1. Fork the repository.
2. Create a feature branch.
3. Make focused changes.
4. Keep the project style consistent.
5. Open a pull request with a clear summary.

## Good contribution ideas

- improve onboarding or documentation clarity
- refine the UI/UX and readability of the guide
- add better screenshots or diagrams
- improve accessibility and mobile responsiveness
- fix errors in the code examples and commands
- add structured walkthrough improvements

## Code and documentation standards

- prefer clear, maintainable HTML and Android resource changes
- keep security and ethics language explicit
- update documentation when workflow changes
- avoid unnecessary complexity or noisy refactors
- keep commands safe, realistic, and educational

## Ethics and scope

This project is intentionally focused on ethical, authorized use. Do not contribute content that supports unauthorized access, malicious behavior, or other unlawful activity.

## Pull request expectations

Please include:

- a clear title
- a concise description of the problem or improvement
- any screenshots if UI changes are involved
- notes on testing or validation

We appreciate thoughtful, well-scoped contributions.
