# Installation guide

This guide explains how to run the project and build the Android app locally.

## Prerequisites

- Android Studio
- Java 17+
- Android SDK
- Git

## Clone the repository

```bash
git clone https://github.com/sonu-999/mobile-harness-guide-android.git
cd mobile-harness-guide-android
```

## Build the app

```bash
./gradlew assembleDebug
```

## Output

The generated APK is typically placed at:

```text
app/build/outputs/apk/debug/app-debug.apk
```

## Useful notes

- The project loads a local HTML guide inside a WebView.
- The educational content is meant for authorized testing and safe learning in environments where you have explicit permission.
