# Security policy

This project is intended for learning, education, and authorized testing of mobile apps you own or are explicitly permitted to assess.

## Expected use

- legitimate educational research
- authorized security review
- Android development learning
- controlled testing in environments where you have permission

## Not allowed

- unauthorized access to devices or apps
- credential theft or unauthorized data collection
- malware, spyware, or malicious payloads
- bypassing protections for personal or third-party systems without consent

## Reporting vulnerabilities

If you discover a security issue in the project itself, please report it responsibly.

Use a private channel or contact the maintainer through GitHub before making the issue public.

## Responsible disclosure

Please avoid publishing sensitive details until a fix is in place and a safe disclosure path has been agreed.

This project is not a tool for malicious activity and should be used responsibly and lawfully.
