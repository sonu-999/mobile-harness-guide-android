Stage 1: Termux & Harness Setup

Install Termux binaries, setup storage permissions, and clone Mobile Harness.

Stage 1 / 7

Step 1.1: Install Termux & Clone Mobile Harness

Ensure you are using F-Droid Termux. Open Termux and run this one-line command to install Python, Java, git, reverse-engineering dependencies, and clone techjarves's Mobile Harness repository:

harness-setup.sh 
# Update repositories and grant storage access
pkg update && pkg upgrade -y
termux-setup-storage

# Install dependencies and clone Mobile Harness
pkg install git python openjdk-17 apktool jadx apksigner aapt -y
git clone https://github.com/techjarves/Mobile-Harness.git
cd Mobile-Harness
pip install -r requirements.txt

When the system pop-up asks for storage permissions, tap Allow.

Step 2.1: Extract Target APK via Package Manager

You can inspect any installed app on your Android device without root permissions. Identify the package name and pull its base APK file into Mobile Harness:

pull-target.sh 
# 1. Search for installed app package name
pm list packages | grep target

# 2. Find internal APK location path
pm path com.example.targetapp

# 3. Copy base APK into Mobile Harness folder
cp /data/app/~~.../base.apk ~/Mobile-Harness/target.apk

Pro Tip: You can also place any downloaded .apk file inside your device's Download folder and copy it from ~/storage/shared/Download/.

Step 3.1: Launch Mobile Harness Decompilation Pipeline

Execute Mobile Harness scripts to disassemble your target app into Smali code, readable Java files, XML layouts, and assets:

run-harness.sh 
cd ~/Mobile-Harness

# 1. Run Mobile Harness CLI to unpack resources & Smali
python main.py --apk target.apk --decompile

# 2. Decompile Java source for beginner readability
jadx -j 2 --no-res -d workspace_java target.apk

Step 4.1: Reverse Engineering & Rebuild Architecture Blueprint

Harness Automation

Utilize Mobile Harness automated routines to map out the application's underlying architecture, network endpoints, activity flows, and local storage:

1. Network Inspection

Scans AndroidManifest.xml and dex code for base URLs, REST contracts, and API keys.

2. Layout Structure

Maps res/layout XML elements to understand app navigation and UI view hierarchies.

3. Logic Identification

Pinpoints authentication routines, validation methods, and feature flags.

4. Clean Replica Spec

Generates clean structural specs for rebuilding the app natively or editing in-place.

harness-analyze.sh 
# Generate complete structural blueprint & network matrix
python main.py --apk target.apk --analyze-endpoints --export-blueprint

Step 5.1: Modify Smali Logic & Patch Resources

Use Acode Editor on Android or Termux built-in nano editor to patch Smali files located inside Mobile-Harness/workspace/smali/:

Smali Beginner Interactive Patch
// ORIGINAL SMALI (Returns False / 0x0): 
.method public checkActivation()Z
    .registers 1
    const/4 v0, 0x0
    return v0
.end method
// MODIFIED SMALI (Returns True / 0x1): 
.method public checkActivation()Z
    .registers 1
    const/4 v0, 0x1    # Set register v0 to true (1)
    return v0
.end method

Step 6.1: Reassemble & Align modified App

Trigger the Mobile Harness rebuild command to recompile modified Smali code and resources back into an APK binary, followed by 4-byte memory alignment:

harness-build.sh 
# 1. Compile modified workspace via Mobile Harness
python main.py --build --use-aapt2

# 2. Perform 4-byte alignment (Required for Android 11+)
zipalign -p -f -v 4 build/unsigned.apk build/aligned.apk

Step 7.1: Sign & Launch Modified Application

Sign your rebuilt APK using APK Signature Scheme V2/V3 and trigger instant Android package installation right inside Termux:

sign-and-install.sh 
# 1. Create a local signing keystore (one-time setup)
keytool -genkey -v -keystore harness.jks -alias harness_key -keyalg RSA -keysize 2048 -validity 10000 -storepass password123 -keypass password123 -dname "CN=MobileHarness, OU=Dev, O=Sonu, C=IN"

# 2. Sign your aligned APK
apksigner sign --ks harness.jks --ks-pass pass:password123 --out ready_to_install.apk build/aligned.apk

# 3. Launch native Android installer
termux-open ready_to_install.apk
⚠️ Note for Beginners: Remember to uninstall the original application from your device first so Android allows installing the newly signed build.

Beginner Troubleshooting Matrix

Split APKs / App Bundles (.apks)

If the app uses split APKs, pass all split files to Apktool or use AntiSplit-M to merge into a single APK first.

Termux Out of Memory (OOM)

Limit JADX memory and thread count:
jadx -j 1 --no-res -d output/ target.apk
